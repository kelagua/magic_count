# 农资场景 AI 语境百科 (Agricultural Context Encyclopedia)

本档旨在为 magic_count (LiteNote) 的 AI 引擎提供行业背景知识，协助优化 System Prompt 和意图识别逻辑，使 AI 能够听懂并精准处理农资店商家的经营指令。

---

## 1. 核心品类字典 (Core Categories)

### 🌱 种子类 (Seeds)
- **大田作物**：玉米（杂交种、先玉、登海）、水稻（杂交稻、常规稻）、小麦、大豆、花生。
- **蔬菜类**：白菜、菠菜、辣椒、番茄、黄瓜、豆角、萝卜、大葱。
- **经济作物**：油菜、棉花、向日葵。

### 🧪 化肥类 (Fertilizers)
- **氮肥**：**尿素** (Urea, 需求量极大)、碳铵。
- **磷肥**：二铵 (磷酸二铵)、过磷酸钙。
- **钾肥**：氯化钾、硫酸钾。
- **复合肥**：通用型 (15-15-15)、专用型 (水稻专用、玉米专用)、掺混肥 (BB肥)。
- **水溶肥**：冲施肥、叶面肥。
- **有机肥**：菌肥、生物有机肥。

### 🔫 农药类 (Pesticides)
- **杀虫剂**：吡虫啉 (蚜虫)、阿维菌素 (红蜘蛛)、康宽 (氯虫苯甲酰胺)、甲维盐。
- **杀菌剂**：多菌灵、代森锰锌 (霜霉病)、嘧菌酯、戊唑醇。
- **除草剂**：**草甘膦** (灭生性)、**草铵膦**、乙草胺 (封闭)、阿特拉津 (玉米地)。
- **调节剂**：芸苔素 (植物仙丹)、多效唑 (控旺)、920 (赤霉素)。

### 🛠️ 农机具类 (Farm Tools & Machinery)
- 小型农机：微耕机、播种机、喷药机。
- 农具：锄头、镰刀、喷雾器。
- 配件：农机配件、灌溉设备。

## 2. 商家常用指令场景 (Common Interaction Scenarios)

### 🚩 赊账场景 (Credit Sales)
- **标准指令**："老王赊了三袋 15-15-15 的复合肥。"
- **混合指令**："李大爷拿了两袋尿素，一共 240 块，先记账上。"
- **口语化指令**："张老三刚才拉了一车肥，没给钱。"
- **AI 提取要点**：
    - **主体**：老王 / 李大爷 / 张老三
    - **商品**：15-15-15 复合肥 / 尿素 / 肥
    - **数量**：三袋 / 两袋 / 一车
    - **金额**：240 块（如明确）/ 需查价（如未明确）
    - **动作**：赊账 / 记账 / 没给钱
    - **状态**：未结清 (Unsettled)

### 💰 结清/还款场景 (Settlement/Repayment)
- **标准指令**："老王刚才微信还了 500 块欠款。"
- **部分还款**："张三现金还了 200，剩下的以后再说。"
- **批量结清**："把李大爷去年的账都结了。"
- **AI 提取要点**：
    - **主体**：老王 / 张三 / 李大爷
    - **金额**：500 / 200 / 全部
    - **支付方式**：微信 / 现金 / 支付宝
    - **动作**：还款 / 结清 / 平账
    - **范围**：单笔 / 全部 / 指定时间段

### 📊 查询统计场景 (Query & Statistics)
- **欠款查询**："老王还欠我多少钱？"
- **期间统计**："本月化肥赊了多少？"
- **客户回款**："帮我分析本月客户回款情况。"
- **AI 提取要点**：
    - **查询维度**：按客户 / 按品类 / 按时间段
    - **统计类型**：欠款余额 / 赊账总额 / 回款率

## 3. 行业"黑话"与缩写 (Industry Jargon)

| 黑话 | 含义 | 示例 |
|------|------|------|
| "三个15" | 15-15-15 的通用型复合肥 | "来三袋三个15" |
| "打药" | 施用农药 | "明天去给玉米打药" |
| "追肥" | 作物生长期间追加的肥料（通常是尿素或复合肥） | "该追肥了" |
| "封闭" | 播种后出苗前的土壤处理除草 | "封闭药打了吗" |
| "控旺" | 使用调节剂抑制植物徒长 | "这玉米得控旺" |
| "二铵" | 磷酸二铵 | "二铵涨了十块" |
| "BB肥" | 掺混肥 | "BB肥比复合肥便宜" |
| "冲施" | 随灌溉水施入的施肥方式 | "冲施肥" |
| "叶面" | 喷施在叶面的肥料或农药 | "打点叶面肥" |
| "菌肥" | 生物有机肥 | "菌肥能改良土壤" |

## 4. 时间语义参考 (Time Semantics)

农资店商家常用的时间表达方式，AI 需能理解并转化为精确时间戳：

| 口语表达 | 含义 | 转换规则 |
|----------|------|----------|
| "刚才" | 不久前 | 当前时间前推 10 分钟内 |
| "今天" | 当天 | 当日 00:00 - 23:59 |
| "昨天" | 前一天 | 前一日 00:00 - 23:59 |
| "上周五" | 上个星期五 | 上周五对应日期 |
| "上个月" | 上一个自然月 | 上月 1 日至月末 |
| "去年" | 上一个自然年 | 去年 1 月 1 日至 12 月 31 日 |
| "开春" | 春季开始 | 当年 2-3 月 |
| "秋收" | 秋季收获期 | 当年 9-10 月 |

## 5. 客户关联逻辑 (Customer Association)

当提到客户名称时，AI 应遵循以下规则：

1. **精确匹配**：优先查找姓名完全匹配的客户。
2. **模糊匹配**：如"老王"可能匹配"王大爷"、"王建国"等，需列出候选让用户确认。
3. **自动关联**：当客户名唯一匹配时，自动关联该客户的历史欠款记录。
4. **新建客户**：如无匹配，提示用户是否新建客户档案。

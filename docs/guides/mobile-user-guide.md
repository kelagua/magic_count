# 移动端用户操作手册 (Mobile User Guide)

本档为 magic_count (LiteNote) 移动端（Android）的用户操作手册，涵盖所有功能模块的使用说明。

---

## 1. 快速入门

### 1.1 安装
1. 下载 APK 文件（由商家提供或从应用内更新获取）
2. 在 Android 手机上安装（需开启"允许安装未知来源应用"）
3. 打开应用，进入登录/注册页面

### 1.2 注册与登录
- **注册**：输入用户名、密码（可选邮箱）
- **登录**：输入用户名和密码
- 登录后进入首页仪表盘

---

## 2. 首页仪表盘 (Dashboard)

首页展示当月核心数据概览：

| 区域 | 内容 |
|------|------|
| 顶部卡片 | 当月收入、支出、结余 |
| 赊账概览 | 未结清赊账总额、待回款客户数 |
| 最近账单 | 最近 5 笔账单记录 |
| 快捷操作 | 记账、AI 对话、查看报表 |

## 3. 记账功能

### 3.1 手动记账
1. 点击底部 **"+"** 按钮或首页快捷操作
2. 选择账单类型：
   - **支出** — 日常开销
   - **收入** — 回款/收款
   - **赊账** — 农户赊购（需选择客户）
3. 输入金额、选择分类、填写描述
4. 选择日期（默认今天）
5. 点击保存

### 3.2 AI 语音记账
1. 进入 AI 对话页面
2. **按住录音按钮**，说出记账内容
   - 示例："老王赊了三袋复合肥，450 块"
   - 示例："李大爷微信还了 200"
3. 松开按钮，AI 自动识别并创建账单
4. **确认卡片**：AI 返回识别结果，确认后入库
5. **语音播报**：记账成功后自动播报结果

### 3.3 AI 拍照记账
1. 进入 AI 对话页面
2. 点击 **📷 拍照** 按钮
3. 拍摄欠条、单据、送货票据
4. AI 自动解析金额、分类和日期
5. 确认后入库

### 3.4 AI 文字对话记账
1. 进入 AI 对话页面
2. 在输入框输入自然语言指令
   - 示例："本月化肥赊了多少？"
   - 示例："帮我分析本月客户回款情况"
3. AI 自动判断是否需要调用工具
4. 如需记账，展示确认卡片

## 4. 客户管理 (Customers)

### 4.1 客户列表
1. 点击底部导航 **"客户"** 标签
2. 查看所有客户列表，显示姓名和欠款余额
3. **搜索**：顶部搜索框输入客户名快速筛选

### 4.2 新增客户
1. 在客户列表页点击 **"+"** 按钮
2. 输入客户姓名（必填）、手机号、地址、备注
3. 点击保存

### 4.3 客户详情
1. 点击客户列表中的某个客户
2. 查看客户基本信息和欠款余额
3. 查看该客户的 **账单历史**（按时间倒序）
4. 可编辑或删除客户

### 4.4 记账时选择客户
- 当账单类型选择 **"赊账"** 时，弹出客户选择器
- 可搜索客户名快速定位
- 如客户不存在，可快速新建

---

## 5. 赊账与还款

### 5.1 赊账记账
1. 新建账单 → 类型选择 **"赊账"**
2. 选择客户（必填）
3. 输入金额、商品描述、分类
4. 保存后账单标记为 **未结清**

### 5.2 单笔还款
1. 在客户详情页找到未结清的赊账
2. 点击该账单 → 选择还款
3. 选择支付方式（微信/支付宝/现金）
4. 确认结清

### 5.3 批量结算
1. 进入 **未结清赊账列表** 页面
2. **多选** 要结清的账单（勾选框）
3. 点击 **"批量结算"** 按钮
4. 选择支付方式
5. 确认结算 → 所有选中账单标记为已结清
6. **TTS 播报**："已结清 X 笔赊账，共 Y 元"

## 6. 报表与统计

### 6.1 统计概览
- 点击底部 **"报表"** 标签
- 查看收入/支出/赊账的汇总数据

### 6.2 日视图

### 6.3 月视图
- 按月查看收支趋势
- 柱状图展示每日/每周收支

### 6.4 年视图
- 按年查看 12 个月的汇总
- 折线图展示月度趋势

### 6.5 分类分析
- 饼图展示各品类占比
- 支持按收入/支出/赊账筛选

### 6.6 趋势分析
- 折线图展示收支趋势
- 支持周/月/年粒度切换

## 7. AI 对话

### 7.1 进入对话
- 点击底部 **"AI"** 标签
- 或从首页快捷操作进入

### 7.2 会话管理
- **新建会话**：点击右上角 **"+"** 按钮
- **切换会话**：点击左上角会话列表图标
- **重命名会话**：长按会话 → 重命名
- **置顶会话**：长按会话 → 置顶
- **删除会话**：长按会话 → 删除

### 7.3 AI 模型配置
1. 进入 **设置** → **AI 模型配置**
2. 添加新配置：
   - 选择服务商（Claude / OpenAI / DeepSeek / Qwen）
   - 输入 API Key
   - 选择模型
   - 可选自定义 API 地址
3. 设为默认配置
4. 测试连接是否成功

### 7.4 支持的输入方式
| 方式 | 操作 | 说明 |
|------|------|------|
| 文字 | 在输入框打字 | 支持自然语言 |
| 语音 | 按住录音按钮 | ASR 转文字后处理 |
| 图片 | 点击 📷 按钮 | 支持拍照或从相册选择，可多张 |

系统在以下场景自动播报：

| 场景 | 播报内容 | 示例 |

| 记账成功 | 金额 + 分类 | "已记录支出 50 元" |

## 12. 常见问题

**Q: 语音识别不准确怎么办？**
A: 尽量在安静环境下录音，语速适中。如识别错误，可在确认卡片中手动修改。

**Q: AI 回复很慢怎么办？**
A: 检查网络连接和 AI 模型配置。DeepSeek 和 Qwen 国内访问更快。

**Q: 如何切换 AI 模型？**
A: 设置 → AI 模型配置 → 切换默认配置。也可在对话中临时切换。

**Q: 赊账记录可以修改吗？**
A: 可以。在账单详情页点击编辑，修改金额、分类、描述等。修改后客户余额会自动更新。

**Q: 数据会丢失吗？**
A: 数据存储在云端 PostgreSQL 数据库，不会因手机问题丢失。换手机重新登录即可恢复。
